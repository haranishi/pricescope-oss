# PriceScope（フリマ出品価格チェッカー）

このOSS版は新規履歴のソース公開です。私用の事業・要件メモ、運用データ、接続先は含めていません。自作部分は [MIT](LICENSE)、依存ライブラリと商標には元の条件が適用されます。

フリマ・オークションへ出品する個人が、商品情報から価格帯と売れやすさをその場で確認するためのWebアプリです。価格だけでなく、改善点とコピペ用の出品文まで提示し、値付けと出品準備の迷いを減らします。

## 背景と目的

出品者は、状態・付属品・需要・季節性を価格へどう反映するか判断しづらく、安売りや売れ残りが起きやすいという前提から作られています。

ローカルの静的プロトタイプを、認証と査定履歴を持つWebサービスへ移したものです。査定自体はログイン不要で、保存・履歴の閲覧・削除はログイン後に利用します。

## 現在できること

- 商品カテゴリ、購入価格、経過年数、状態、需要などから4つの価格帯を即時計算
- 売れやすさスコア、査定信頼度、価格へ効いた要因、改善チェックを表示
- ルールベースで出品タイトルと説明文を生成し、まとめてコピー
- メールアドレスとパスワードによるアカウント作成・ログイン
- 査定結果の保存、検索・カテゴリ絞り込み付き履歴、詳細表示、削除、再査定

## 設計上の判断

査定は外部の相場APIや実売データを参照せず、`logic_version = "v1"` の固定係数で計算します。入力中も待たせないためブラウザ上で計算し、保存時には同じロジックをサーバー側でも再実行して、改ざんされた計算結果を保存しない構成です。

履歴には入力と結果のスナップショット、ロジックのバージョンを残します。将来係数が変わっても、当時の査定が何に基づくか追跡できるようにするためです。

要件書では Supabase を想定していましたが、現行実装は Neon PostgreSQL、Drizzle ORM、NextAuth のCredentials認証を使用します。

## 前提と動作条件

- Node.js と npm
- Neon PostgreSQL の接続文字列 `DATABASE_URL`
- NextAuth 用の `AUTH_SECRET`
- スキーマは Drizzle マイグレーションを適用して用意する

```bash
npm install
cp .env.example .env.local
# DATABASE_URL と AUTH_SECRET を自分の環境に設定してから起動します。
npm run dev
```

## 重要な注意点

- 表示額は固定係数による参考価格であり、実際の取引相場・真贋・成約を保証しません。
- `v1` の係数、丸め、スコア算出を変えると既存査定との比較可能性が失われます。変更時はロジックバージョンを上げ、ゴールデンテストも更新してください。
- 保存APIはクライアントから渡された結果を信用せず再計算します。この境界を崩すと履歴の整合性が失われます。
- 認証は独自のメール＋パスワード方式です。Supabase Auth や Google OAuth は現行実装にはありません。
- `usage_events` テーブル定義はありますが、イベントを記録する処理は未実装です。
- 実売価格・成約日数・値下げ回数の列はありますが、実売報告を登録する処理は未実装です。

## 対象外・未完了

- Stripe等による課金とプラン制御
- AIによる出品文生成、画像からの商品状態判定
- メルカリ、Yahoo!オークション、eBay等からの実売価格取得やスクレイピング
- 複数サービスへの一括出品、JAN・型番スキャン、需要予測
- 業者向けのチーム、CSV出力、外部API提供
